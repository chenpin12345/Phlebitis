## Section A — 各主題關鍵結論（含證據等級、主張類型、現在 vs 未來）

### Takeaway
報告的總論點（L3）：在 14 位病人、56 張已標記照片下，所有「進階」方法都受同一天花板限制——**可交換單位是病人，不是照片**——所以校準、保形覆蓋率、OOD 門檻、熱圖定位率、集成增益都無法以有意義精度被驗證；現在最值得做的是四件便宜的事：(1) 資料計數與病人分組防洩漏可稽核；(2) 以已知混淆因子清單做捷徑學習檢查；(3) LINE 回覆改「結果須人工確認後才送出」＋每人每日配額、push 監控、獨立影子佇列；(4) 凍結 DINOv2 特徵的 kNN／原型基線，同一組嵌入兼作相似案例檢視（排除同病人）與 OOD 閘門。**未來即使到約 1,000 張，決定證據力的仍是病人數**；若 1,000 張只來自 50 位病人，校準與保形結論幾乎與現在相同（L3）。

### Cited Findings

#### A0 資料前提（報告第 0 章）
- **資料數字不一致**：專案背景寫約 120 張，但二分類「陽性 47、正常 9」＝56 張；分期「正常 9、第一期 23、第二期 24」＝56 張；報告「無法判斷，也不自行補數字」，所有計算以 **n=56 張、14 位病人、正常 9 張** 為基準；請資料負責人確認 (a) 120 與 56 差額是什麼照片；(b) 每位病人照片數與日期分布；(c) 正常 9 張來自幾位病人；(d) 約 24 張有病灶框的照片分屬幾位病人、哪些分期；這四個數字會改變第 9–13 章可行性判定（報告 L17–19）。
- **有效樣本數是病人數，而且比 14 更少**：群聚資料的分佈無關保證要以「群」為單位（Dunn, Wasserman, Ramdas 2023，JASA，[B]，[來源](https://arxiv.org/abs/1809.07441v4)）；CV 在 n≈100 時誤差棒約 ±10%，各折標準誤嚴重低估（Varoquaux 2018，NeuroImage，[B]，[來源](https://arxiv.org/abs/1706.07581)）。本報告推論：有效 n 接近 14，正常類更接近「正常照片來自的病人數」（未知）；保留 25–30% 病人作獨立測試集＝約 3–4 位病人、14–18 張（L21–23）。
- 正常類 0 次誤報的 Wilson 95% CI 仍是 0–30%；完美校準模型在 n=56 時 10 箱 ECE 平均約 0.12（研究筆記模擬）（L3）。

#### A0b 本範圍六大風險（L29–41）
1. **評估本身不可靠**：Varma & Simon 虛無資料偏誤 −12.2%（shrunken centroids）、−8.3%（SVM），巢狀 CV 接近獨立測試誤差（BMC Bioinformatics 2006，[B]，[來源](https://pmc.ncbi.nlm.nih.gov/articles/PMC1397873)）；Cawley & Talbot：模型選擇損失「可能大得驚人」（JMLR 2010，[B]，[來源](https://www.jmlr.org/papers/v11/cawley10a.html)）。「每多試一種設定、提示詞、TTA 政策或門檻，都會吃掉這個預算」（L31）。
2. **來源與人工物捷徑**：Zech 2018 胸片辨識醫院 99.95%／99.98%、只用醫院排序 AUC 0.861（PLOS Med，[B]，[來源](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.1002683)）；Winkler 2019 筆跡使特異度 84.1%→45.8%、裁切後 97.2%（JAMA Dermatol，[B]，[來源](https://pubmed.ncbi.nlm.nih.gov/31411641/)）；本專案「義大 vs LINE」、檔名規則分期標籤、膠帶、敷料、筆跡、床單同型（L33）。
3. **對公開 LINE 使用者自動送「結果」**：牴觸「模型建議須人工確認」與「不宣稱臨床診斷」（L35）。
4. **隱性洩漏**：同病人照片會在 kNN 檢索、校準器擬合、保形校準集、OOD 門檻、合成資料生成器訓練中重新混入；scikit-learn `CalibratedClassifierCV` 用整數 `cv=3` 會改用不分組的 StratifiedKFold（L37）。
5. **公開服務資源耗盡與費用**：程式碼（2026-10-31 閱讀）已有每人同時一件、全域佇列上限 4，但**沒有每人每日配額**；影子模型在主 worker 內、回覆後同步執行，會擋住下一位、把更多案件推過 45 秒門檻改走計費 push；LINE 台灣輕用量每月 200 則免費且不可加購（LINE Biz 台灣調價公告，2026-09-01 發布、2026-11-01 生效，[A]，[來源](https://tw.linebiz.com/column/LINEOA-2026-Price-Plan/)）（L39）。
6. **標籤雜訊**：71 種量表只有 VIP、INS、PVC ASSESS 做過心理計量測試，「沒有一個被完整驗證」；INS 評分者間 kappa 0.45；PVC ASSESS 紅斑現場 0.40、照片 0.58（Ray-Barruel 2014，[B]，[來源](https://pmc.ncbi.nlm.nih.gov/articles/PMC4237185)）（L41）。

#### A1 擴散模型合成資料（第 1 章，L87–143）
- **結論**（本報告推論，依研究證據）：現在**不建議**用合成資料訓練或評估任何模型；未來約 1,000 張可作「逐折生成、只用於訓練、逐張人工確認、合成：真實 ≤1–2:1」的消融，預期效益至多小幅（L91）。
- 研究證據（正面）：Ktena 2024（Nat Med 30:1166–1173，DOI 10.1038/s41591-024-02838-6，[B]，[來源](https://arxiv.org/abs/2304.09218)，**摘要層級**）分布外測試：病理 +7.7%、胸片 +5.2% 且公平性差距縮小 44.6%、皮膚科高風險敏感度 +63.5%、公平性差距縮小 7.5 倍；作者明言不能取代真實資料。Sagers 2023（arXiv 2308.12453，[D]，[來源](https://arxiv.org/abs/2308.12453)）458,920 張合成影像，合成：真實 >10:1 後持平，效益「substantially smaller」於增加真實影像，每任務真實 1–228 張（設計細節為搜尋摘要層級）。Sagers 2022 以 DALL·E 2 每病 8 張種子 inpainting，摘要無數字、為雲端服務（[D]，[來源](https://arxiv.org/abs/2211.13352)）。MAGIC：擴散模型「frequently produce medically inaccurate images」，經專家準則 MLLM 評審後 20 類 +9.02%、少樣本 +13.89%（NeurIPS 2025，[B]，[來源](https://arxiv.org/abs/2506.12323)）。DermaFlux「up to 6%」僅搜尋摘要、未驗證（[D]，[來源](https://arxiv.org/abs/2603.16392)）（L95）。
- 傳統增強：Perez 2018 最佳 13 種增強情境 AUC 0.882 > ISIC 2017 冠軍 0.874（皮膚鏡；[D]，[來源](https://arxiv.org/abs/1809.01442)）；Rao 2023 CutMix 校準改善最多、CutOut 常變差（[D]，[來源](https://openaccess.thecvf.com/content/ICCV2023W/CVAMD/html/Rao_Studying_the_Impact_of_Augmentations_on_Medical_Confidence_Calibration_ICCVW_2023_paper.html)）（L97）。
- 反面證據：Carlini 2023 可抽出「over a thousand」張訓練影像（USENIX Security，[B]，[來源](https://www.usenix.org/conference/usenixsecurity23/presentation/carlini)）；Somepalli 2023 小資料集頻繁複製、文字條件更嚴重（CVPR，[B]，[來源](https://arxiv.org/abs/2212.03860)）；Dar 等 v1 最多 41.7%（CT）、19.6%（MR）、32.6%（X 光）被記憶，v2 約 40.9% 病人資料被記憶、78.5% 合成樣本被判為複本，數字隨版本變動（[D]，[來源](https://arxiv.org/abs/2402.01054)）；FID 與 IS「不適合」偵測記憶（Akbar 2025，[C]，[來源](https://arxiv.org/abs/2305.07644)）；diffusers 文件：DreamBooth 對超參數敏感、易過擬合（[A/E]，[來源](https://huggingface.co/docs/diffusers/training/dreambooth)）（L101）。
- **未找到可靠證據**：擴散增強對傷口／IV／靜脈炎照片有效；<約 100 張、病人分組評估的擴散微調；合成影像盲法臨床分期的標籤忠實度。唯一照片型 AI 靜脈炎研究為試驗登錄 NCT07889895，尚無結果（[A]／[E] 筆記間分級不同，[來源](https://clinicaltrials.gov/study/NCT07889895)）（L103）。
- **現在（14 位）不建議**（本報告推論）：每折生成器只看到約 9–10 位病人，預期效益約零或負；四風險＝近乎複製特定病人的手／刺青／敷料／背景、學到來源風格、生成器看過驗證／測試病人使 CV 膨脹、合成「第二期」＝未驗證標籤牴觸「不偽造標籤」。至多做單一折 LoRA 沙盒負面結果實驗，**任何合成影像不得進入任何報告模型**（L107）。
- **未來有條件適用**：逐折、只用於訓練、優先 inpainting／ControlNet 只改 IV 部位、合成：真實 ≤1–2:1、逐張臨床審閱、同切分同種子配對消融為唯一證據；預期至多少數子群數個百分點平衡準確率，未經證實（L109）。
- 應用表（L111–118）：證據強度「正面證據 B／D，均來自數千張以上皮膚資料；反面（記憶）證據 B 且一致」；預期效益「現在 ≈0 或負；未來小」；最少資料「未找到可靠證據；本報告推論每類至少數十位病人」；接入「離線 `tools/synth/`，讀取折清單，本機 `train_dreambooth_lora.py`（不加 `--push_to_hub`）」；GPU「SD 1.5 LoRA／DreamBooth：16 GB 需 8-bit Adam＋gradient checkpointing；12 GB 另需 xFormers 與 `set_grads_to_none`；8 GB 需 DeepSpeed stage 2 CPU offload 與約 25 GB 系統記憶體；訓練文字編碼器需 ≥24 GB（diffusers 文件，[A/E]）；SDXL／Flux 記憶體需求未驗證」；主要風險「記憶複本、來源捷徑、評估污染、未驗證標籤」。
- 實作（本報告推論，L122–135）：先做便宜增強（水平翻轉互換 LH/RH 外觀但不改標籤、小角度旋轉、保留 IV 部位隨機縮放裁切、亮度／對比／gamma／白平衡；**色相抖動必須很小**；JPEG 壓縮與模糊模擬 LINE；mixup／CutMix 校準方向須量測）；病灶複製貼上比照合成影像規則。SQLite 新增 `is_synthetic`、`generator_id`、`generator_train_patient_ids`、`fold_id`、`seed`、`prompt/condition`、`parent_real_image_id`、`nn_distance_dinov2`、`nn_distance_sscd`、`review_status`、`reviewer`、`review_date`；評估查詢一律 `is_synthetic=0`；訓練須明確 `--use-synthetic`（預設關閉）且只收 `review_status='approved'`。
- 驗證（L139）：配對消融只在**只含真實影像**的評估集報平衡準確率、正常誤報率、macro-F1 配對差值＋病人層級 bootstrap CI；14 位病人「CI 幾乎必然跨零，必須寫成『未證實有益』」；DINOv2 與 SSCD（Pizzi 2022，[D]，[來源](https://arxiv.org/abs/2202.10261)）最近鄰相似度記憶檢查，門檻參照「同病人不同日期真實照片對」分布；FID／precision-recall 在 n≈100 不可信。

#### A2 少樣本、度量學習與相似案例檢索（第 2 章，L147–203）
- **結論**（研究證據一致）：跨領域（含皮膚科）少樣本中，好特徵上的最近鄰／原型、置中＋L2、線性探針或微調追平或勝過情節式元學習。最符合證據的做法：凍結 DINOv2 + cosine kNN、最近類別平均原型或既有邏輯斯迴歸；**不建議**在 14 位病人上訓練 Siamese、triplet 或元學習；相似案例檢索可作研究者端決策輔助，但證據顯示效用不如類別機率，且必須排除同病人（L151）。
- 證據：Snell 2017 原型網路（NeurIPS，[B]，[來源](https://arxiv.org/abs/1703.05175)）；SimpleShot 在 miniImageNet 5 設定中 3 個勝出（[D]，[來源](https://arxiv.org/abs/1911.04623)）；Chen 2019 跨領域標準微調「compares favorably」（ICLR，[B]，[來源](https://arxiv.org/abs/1904.04232)）；BSCD-FSL「所有元學習方法平均準確率落後簡單微調 12.8%」，皮膚科與放射最難（ECCV 2020，[B]，[來源](https://arxiv.org/abs/1912.07200)）（L155）。
- 業界慣例：DINOv2 README（[E]，[來源](https://github.com/facebookresearch/dinov2)）ViT-S/14（21M）ImageNet k-NN 79.0%、線性 81.1%；ViT-B/14（86M）82.1%／84.5%；Apache-2.0。DINOv2 放射 9 基準「competitive」（Baharoon，[D]，[來源](https://arxiv.org/abs/2312.02366)）。PanDerm 約 215 萬張未標記皮膚影像預訓練，常以 5–10% 標籤勝過既有模型，勝過 DINOv2 ViT-L 基線（Yan 2025，Nat Med，DOI 10.1038/s41591-025-03747-y，[B]，[來源](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12353815/)）。Derm Foundation 模型卡：嵌入上線性分類器比 BiT-M 高 10–15%，需接受 HAI-DEF（[E]，[來源](https://huggingface.co/google/derm-foundation)）（L157）。
- 相似案例：Tschandl 2020「**AI 多類別機率優於內容式影像檢索（CBIR）**」，錯誤 AI 會誤導包括專家（Nat Med 26:1229–1234，[B]，[來源](https://europepmc.org/article/MED/32572267)；增益數字未驗證）；SMILY 加精煉工具後診斷效用與信任提高（Cai 2019，CHI，[B]，[來源](https://arxiv.org/abs/1902.02960)）（L159）。PanDerm 讀者研究 top-3 54%→63.4% 是分類輔助非檢索（L163）。
- **未找到可靠證據**：小樣本病人分組皮膚照片上 Siamese／triplet vs kNN；BSCD-FSL 未處理病人分組（本報告推論、未核實原文）（L163）。
- **現在**：kNN／原型基線與研究者端相似案例檢視「適用」；度量學習訓練「不建議」。本報告推論：同病人照片是最相似配對，Siamese 主要會學到病人身分；正常 9 張使 k>3 幾乎不可能形成正常多數，需類別平衡投票或原型。**未來**：比較 DINOv2 s/b/l 與皮膚科基礎模型（先完成 safetensors 轉換、授權審查、使用者本人接受 HAI-DEF）、以人工確認框裁切嵌入；標記資料增加後預期線性或微調超越 kNN（L167）。
- 應用表（L169–176）：證據強度 B（多篇一致）；預期效益「現在：準確率持平、可解釋性中；未來：中」；最少資料「kNN 對任何 n 可運作，但 9 張正常照片使 CI 極寬；靜脈炎特定最少 n：未找到可靠證據」；接入 `transformers` `AutoModel`（`facebook/dinov2-small`，已在用）＋`sklearn.neighbors.NearestNeighbors(metric="cosine")`；GPU「本報告推論：21M／86M 參數，120–1,000 張推論在任何 8–16 GB GPU 或 CPU 上皆輕鬆；kNN 為 CPU 毫秒級」；風險「同病人檢索、過度信任檢視器、展示他人照片的隱私」。
- 實作／驗證（L180–203）：SimpleShot 式 CL2N，統計量只用訓練折、冗餘排除同病人、類別平衡距離加權投票、原型＝病人平均的類別平均；嵌入快取鍵 `image_id`、`model_id`、`preprocess_hash`；面板（FastAPI＋React）每類 top-k、排除同病人、研究警語，使用者選擇只在明確確認後寫入；**絕不讓 LINE 使用者看到其他使用者的照片**；檢索以「不同病人、相同分期」precision@k 評估；另做「不排除同病人」錯誤對照量化膨脹。

#### A3 多任務與多模態（第 3 章，L207–256）
- **結論**：14 位病人下共享骨幹偵測＋二分類＋分期沒有小資料證據、有負遷移風險；較可稽核的是兩階段管線：YOLO 偵測 → 人工確認框 → 擴張裁切（保留周邊皮膚）→ 凍結特徵分類器、分期用順序頭。臨床資訊作危險因子證據堅實，但影像＋臨床融合增益溫和（約 1–7 點平衡準確率），可能因缺失值捷徑在測試集消失；現在**只收集、分開分析、不融合**（L211）。

#### A4 集成、TTA 與知識蒸餾（第 4 章，L260–310）
- **結論**：研究證據顯示深度集成穩定改善校準與偏移穩健性，約 5 成員足夠；3 折模型平均便宜合理，但**集成成效只能在三個模型都沒看過的病人上報告**；現在集成用來產生「折間分歧」訊號交人工審閱，而非宣稱準確率提升；TTA 不是免費增益，只建議作不確定性訊號；KD 現在沒有價值（L264）。
- 證據：Lakshminarayanan 2017（[B]，[來源](https://arxiv.org/abs/1612.01474)）；Ovadia 2019「a relatively small ensemble size (e.g., 5) is sufficient」、偏移下「confidently wrong」、TS 偏移下常更差（NeurIPS，[B]，[來源](https://papers.nips.cc/paper/2019/hash/8558cb408c1d76621371888657d2eb1d-Abstract.html)）；Mehrtash 2020 分割（[B]，[來源](https://pmc.ncbi.nlm.nih.gov/articles/PMC7704933)）；SIIM-ISIC 冠軍 CV AUC 0.9600、私榜 0.9490（Ha 2020，[D]，[來源](https://arxiv.org/abs/2010.05351)；資料量為本專案三個數量級以上）（L268）。TTA：Wang 2019（[B/C]，[來源](https://arxiv.org/abs/1807.07356)）、Hekler 2023「substantially better calibration」（AAAI，[B]，[來源](https://ojs.aaai.org/index.php/AAAI/article/view/26735)）（L270）。KD：Stanton 2021 最佳一致率約 85% top-1（[B]，[來源](https://arxiv.org/abs/2106.05945)）；MedAlmighty 各醫學任務不一致（[C]，[來源](https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2025.1527980/full)）（L272）。
- 反面：Shanmugam 2021 TTA 把許多正確預測改錯、簡單平均次佳（ICCV，[B]，[來源](https://openaccess.thecvf.com/content/ICCV2021/html/Shanmugam_Better_Aggregation_in_Test-Time_Augmentation_ICCV_2021_paper.html)）；單一作者預印本 MedMNIST v2 標準 TTA「consistently degrades accuracy」，最多降 31.6 個百分點（[D]，[來源](https://arxiv.org/abs/2604.09697)）；HAI-DEF 蒸餾學生屬衍生物（[A]）（L276）。
- **現在**：集成「有條件適用（作不確定性訊號）」：每張 CV 影像都在 3 折模型中 2 個的訓練集內，用 CV 影像評分集成會洩漏；有效選項 (a) CV 前凍結獨立測試病人只評一次；(b) 巢狀 CV（外層留 2 人、約 7 外層折）；(c) OOF 標「單一模型表現」、集成標「只在獨立病人上評估」；獨立測試集約 3 位病人無法顯示差異。TTA「不建議用於準確率；可作不確定性旗標」，顏色抖動 TTA 不適用。KD「不建議」，新增溫度與 α 兩選擇變數；以未標記 LINE 照片蒸餾接近偽標籤，教師輸出不得成為標籤。**未來**：5 成員集成值得但證據力由病人數決定；TTA 有條件；KD 只在有具體 CPU／行動部署需求（L280–284）。
- 方法表（L286–290）：3 折集成 B（大資料）／現在校準略改善、分歧訊號；未來中／GPU「推論成本×成員數；B0／DINOv2-small 3–5 個成員容於 8 GB」／風險「未經有效證據宣稱『更準』」；TTA B（正反）、D（醫學負面）／現在≈0／「推論×K（K≈3–8），與 3 成員集成合計 9–24 次前向仍可互動」／「靜默準確率損失」；KD B、C／現在≈0／「以快取 DINOv2 特徵蒸餾 B0 學生，容於 8 GB」／「少數類退化、授權繼承」。
- 實作／驗證（L294–310）：SQLite 共同 `ensemble_id`；回傳平均與成員離散度；YOLO 集成需 WBF／NMS 屬額外工程、偵測維持單模型；`tta_policy` 存每筆預測；Ultralytics `augment=True` 對 YOLO11/26 本資料是否有益未知；分歧旗標 `s_max` 由 OOF 分布選定並人工核可、版本化、不在獨立測試集上調整；預登記 TTA＝原圖＋水平翻轉＋±10° 旋轉，機率平均；risk-coverage 檢查分歧樣本錯誤率；TTA 開啟後必須重新校準。

#### A5 SAM 分割與定量量測（第 5 章，L314–355）
- **結論**：框提示 SAM 家族適合當**標註助手**（草稿遮罩、人修正）；零樣本在邊界模糊、低對比目標不穩定，瀰漫性紅斑正是此類；**未找到可靠證據**評估 SAM 在靜脈炎或瀰漫性紅斑上；未校正 LINE 照片計算紅斑面積或色彩指數不可靠；有色卡與比例尺、垂直拍攝時傷口面積 ICC 約 0.97–0.99。現在只用 SAM／MobileSAM 加速約 24 張框圖人工遮罩並試辦拍攝流程；未來以校正後可解釋特徵（Δa*、cm²、條索長度）餵簡單分類器作輔助對照（L318）。
- 證據：Mazurowski 2023 19 資料集「notably better with box prompts than with point prompts」，IoU 0.1135（脊椎 MRI）到 0.8650（髖部 X 光）（[B]，[來源](https://arxiv.org/abs/2304.10517v3)）；Huang 2024 53 資料集約 105 萬張，零樣本「is not sufficient」，微調 Dice +4.39%（ViT-B）、+6.68%（ViT-H）（[B]，[來源](https://arxiv.org/abs/2304.14660v7)）；MedSAM 約 157 萬組、86 內部 60 外部任務，皮膚鏡代表性不足（Nat Commun 15:654，[B]，[來源](https://www.nature.com/articles/s41467-024-44824-z)）（L322）。

- 拍攝流程試辦（本報告推論，L347）：IV 部位旁平放同設計小卡（白／灰／紅膚色色塊＋ArUco 或 QR 或 2 cm 比例尺）；手機平行皮膚約 20–30 cm；不用閃光或統一閃光政策；盡可能拍對側；記錄置入後時間、部位代碼、VIP／INS 逐項；避免筆跡、身分標籤、臉；記錄膠帶與敷料；**色卡本身曾成為捷徑（Nauta 2021）**，所有類別須一致出現。授權：SAM／SAM 2／MobileSAM Apache-2.0；**Ultralytics 本身為 AGPL-3.0（研究筆記未在本輪核實，任何散布前須確認）**。

#### A9 機率校準（第 9 章，L529–606）
- **結論**：現在只有溫度縮放（1 參數）與 Platt（2 參數）技術上可擬合，且必須用病人分組 CV 的 OOF 分數擬合；但校準**無法被可信驗證**：研究筆記模擬完美校準模型 n=56 時 10 箱 ECE 平均約 0.124、校準斜率 95% 區間約 0.59–1.92；**UI 必須維持「非疾病機率」字樣**；isotonic、Dirichlet、matrix scaling 不可用。未來約 1,000 張：溫度／向量縮放／Dirichlet（含 ODIR）可行，isotonic 仍邊緣；斜率約 ±0.13，前提是病人數足夠且醫院與 LINE 分開報告（L533）。
- 研究證據：Guo 2017 溫度縮放最有效（ICML，[B]，[來源](https://arxiv.org/abs/1706.04599v1)；驗證集數千至數萬）；Kull 2019 Dirichlet＋ODIR（NeurIPS，[B]，[來源](https://proceedings.neurips.cc/paper/2019/hash/8ca01ea920679a0fe3728441494041b9-Abstract.html)；審稿質疑退化為向量縮放）；Niculescu-Mizil & Caruana 2005 資料稀少時 isotonic 較易過擬合（[B]，[來源](https://mlanthology.org/icml/2005/niculescumizil2005icml-predicting)）（L537）。
- 業界慣例（scikit-learn 1.9.1，[A]，[來源](https://scikit-learn.org/stable/modules/generated/sklearn.calibration.CalibratedClassifierCV.html)）：`method='sigmoid'|'isotonic'|'temperature'`，`'temperature'` 1.8 版新增、原生多類別；官方原文「Isotonic calibration is not recommended when the number of calibration samples is too low (≪1000) since it then tends to overfit」；`ensemble=True/False` 行為；`cv` 可傳 splitter 或索引 iterable；**官方 API 頁未記載 `groups` 參數**；`FrozenEstimator` 時「The user has to take care manually that data for model fitting and calibration are disjoint」（L539）。
- 評估：Kumar 2019 histogram binning O(B/ε²)、scaling O(1/ε²)，Platt／TS 真實誤差大於報告值（[B]，[來源](https://papers.nips.cc/paper/8635-verified-uncertainty-calibration)）；Roelofs 2022 ECE_bin 有偏、對完美校準偏誤最大、等量分箱較小（[B]，[來源](https://proceedings.mlr.press/v151/roelofs22a.html)）；Van Calster 2019 STRATOS：mean／weak／moderate／strong，彈性曲線建議 ≥200 有事件＋≥200 無事件，**小資料集只評估 weak calibration 可辯護**，反對 Hosmer–Lemeshow，高盛行率開發模型在低盛行率處會高估（[B]，全文已讀，[來源](https://pmc.ncbi.nlm.nih.gov/articles/PMC6912996/)）；Riley 2021 外部驗證範例（事件率 0.018）需 9,835 人（177 事件）（[B]，摘要層級，[來源](https://eprints.keele.ac.uk/id/eprint/9707)）；Saerens 2002 EM 先驗調整（[B]，[來源](https://mlanthology.org/neco/2002/saerens2002neco-adjusting)）（L541）。
- 研究筆記計算（L543，scipy 於專案 .venv，假設照片獨立＝樂觀下界）：見 Section C。參數數（K=3）：溫度 1、Platt 2、beta 3、向量縮放 6、matrix／Dirichlet 12、isotonic 非參數；現在 Dirichlet「每個參數不到 1 張正常樣本」。
- 反面：Ovadia 2019 輕微偏移下事後校準失效、TS 常更糟（[B]）；醫學校準證據多為分割；**未找到可靠證據**：具名皮膚科／照片型分類校準研究、Riley 公式對 CNN 適用性、群聚資料 Brier／ECE 偏誤校正、scikit-learn metadata routing 傳 `groups`；Platt 1999、Zadrozny & Elkan 2002、beta calibration、Nixon 2019、netcal 未查證（L547）。

#### A10 保形預測（第 10 章，L610–698）
- **結論**：保證是**邊際**的、只對可交換單位成立，本專案單位是病人；依 Dunn 2023 每位病人抽一張，校準點 ≤14；若保留約 20–30% 病人測試，校準病人只剩約 3–4 位，最小可達 α 約 0.25，覆蓋率 90% 區間約 0.37–0.98；Mondrian 在病人層級更不可能；現在只能作「**實驗性分流規則**」，不是保證。未來校準病人 ≥約 70 才接近教材 ε=0.05 精度量級，約 200 位以上才穩定；醫院 vs LINE 偏移破壞可交換性（L614）。
- 證據：Angelopoulos & Bates（arXiv 2107.07511，[D]，期刊版未查證，[來源](https://ar5iv.labs.arxiv.org/html/2107.07511)）q̂＝⌈(n+1)(1−α)⌉/n 分位；1−α ≤ P ≤ 1−α+1/(n+1)；條件覆蓋 Beta(n+1−l, l)；粗略建議約 1,000 校準點；表（δ=0.1、α=0.1）ε=0.1→n=22、ε=0.05→102、ε=0.01→2,491；90% 邊際覆蓋可同時對某子群 100%、另一子群 0%（L618）。Dunn 2023（JASA 118(544):2491–2502，[B]，定理已讀）：群內多觀測不可交換，**single subsampling** 有限樣本覆蓋 ≥1−α（目標「新病人的新觀測」），群數 k > 1/α − 1（α=0.1 約需 ≥10 群）；repeated subsampling ≥1−2α、實務接近 1−α；CDF pooling 只有漸近覆蓋（L620）。Lee, Barber, Willett 階層資料（[D]）。
- 其他方法（L622）：jackknife+／CV+ 最壞 1−2α（Barber 2021，[B]，二手確認，[來源](https://www.doi.org/10.1214/20-AOS1965)）；APS（[B]）；RAPS ImageNet α=10% APS 平均集合 19、RAPS 約 2（[D/B]，[來源](https://arxiv.org/abs/2009.14193v5)）；Ding 2023 clustered conformal（[B]）；Tibshirani 2019 加權保形（[B]）；conformal risk control 可控 FNR（ICLR 2024，[B]）；Geifman 2017 選擇性分類 risk-coverage（[B]）。
- 醫學應用（L624）：Olsson 2022 STHLM3（訓練 7,788 片／1,192 名、測試 3,059 片／676 名），非典型子集錯誤 3（2%）vs 44（25%），標記 143（80%）為不可靠；**Nature Communications 2022;13:7761**（更正：非 BJC）（[B]，[來源](https://www.nature.com/articles/s41467-022-34945-8.pdf)）；Lu 2022 依膚色條件保形（AAAI，[B]）；Ordinal APS 409 筆腰椎 MRI（[D]，[來源](https://arxiv.org/abs/2207.02238v1)）。
- 函式庫（業界慣例，L626）：MAPIE v1.x `SplitConformalClassifier(estimator, confidence_level, conformity_score="lac", prefit=True)`、`fit → conformalize → predict_set`，`confidence_level`＝1−α（[E]；groups 未查證）；crepes 支援 Mondrian、`crepes.martingales`（[E]）；TorchCP（JMLR 26，2025；**LGPL-3.0**）無內建溫度縮放（[A/E]）；**三者皆以樣本為單位，不會自動處理病人群聚**。
- 研究筆記 Beta 表與衍生數字：見 Section C。**未解差異**：筆記以「P(1−α−ε ≤ C ≤ 1−α+ε) ≥ 0.9」算得 ε=0.1→n=11、ε=0.05→n=90，與教材表 22、102 不一致，未能查清；報告引用教材原表（L648；研究筆記 calibration_conformal.md L166 相同陳述）。
- **現在**：病人層級 split conformal（α=0.2 或 0.25）「有條件適用」（病人分組 OOF → 每病人抽 1 張 → split conformal；並列「照片為單位」錯誤對照）；Mondrian 與保形風險控制「不建議」（CRC 以 α=0.1 控正常誤報需 0/9，會把門檻推到幾乎不判陽）；n≤14、α=0.1 時 q̂＝最大校準分數，任何比校準集更差的新病人得全類別集合（L656）。**未來**：校準病人 ≥70（n=67 時 P(C<0.85)=0.051）：Ordinal APS＋病人層級 split／repeated subsampling；正常類 Mondrian（每類 ≥約 70 位）或 clustered；CRC 控正常誤報；醫院／LINE 分開校準（Mondrian by source）；若 1,000 張只來自約 50 位病人（校準約 10–20 位），結論幾乎同現在（L658）。
- 應用表（L660–666）：證據「B（理論與方法）；小樣本醫學實證：未找到可靠證據」；預期「現在：低（教育與分流規則）；未來：中」；最少資料「α=0.2：形式上 ≥5 位校準病人，本報告建議實質 ≥40；α=0.1 且 ±5% 精度：≥約 70–100 位」；接入「在 MAPIE／TorchCP／crepes 前自行做每病人一張的子抽樣」；GPU 可忽略。
- 實作（L670–688）：二分類 LAC（s=1−p̂_y）；三分期優先 Ordinal APS 或只允許連續區間，避免 {正常, 二期}；先溫度縮放再保形（不影響覆蓋，只影響集合大小）；`conformal_qhat`、`patient_level_qhat`（B=1 才有有限樣本 ≥1−α；取 B 個 q̂ 中位數「不是 Dunn 證明的程序」）。
- 驗證／風險（L694–698）：報每折病人為單位經驗覆蓋、平均集合大小、單例／空集合比例＋病人 bootstrap CI＋Beta 理論區間；影子模式事後標記、crepes martingales 檢驗可交換性、按月報告；UI 應寫「研究用不確定性分流規則，基於 n 位病人校準，覆蓋率估計區間 x–y」；**不可依監測結果自動重設 q̂ 或加權權重**；空集合不是 OOD 保證；所有函式庫可純本機。

#### A11 分布外偵測與拒答（第 11 章，L702–758）
- **結論**：沒有一種 OOD 分數全勝；遠 OOD（迷因圖、截圖、文件、食物、風景）遠優於近 OOD（腿、頸、其他皮膚病、瘀青、沒有 IV 的手）；醫學影像上複雜方法常不勝 MSP，皮膚科近 OOD 即使 14,000 例與專門訓練也只到 AUROC 約 72–83；因此**本平台不能宣稱偵測近 OOD**，目標是篩掉遠 OOD、其餘不確定者送人工；最便宜且證據支持最高：**L2 正規化凍結特徵上的 kNN 距離**，再以 MSP 或 energy 作第二訊號；Mahalanobis 在極小非高斯資料不可靠；守門分類器屬未來（L706）。

- **現在**：DINOv2 kNN＋MSP／energy＋本機 CLIP 零樣本邊際＋啟發式＋臉部閘門「適用」（僅宣稱遠 OOD 篩除）；Mahalanobis、ViM、學習式守門「不建議」（從約 120 個 384 維向量估共變異數奇異或病態；守門頭可能把醫院背景學成 ID 線索、拒收所有 LINE 照片）；ODIN 跳過；YOLO 在 τ 以上無任何 IV／手臂框本身是強領域訊號（推論，無已發表證據）。平台特有失敗模式 (1) 共變量偏移真實照片被判 OOD；(2) 近 OOD 被接受得到自信但無意義分期；(3) 正常只有 9 張，民眾正常手臂可能被錯誤拒收。**決策規則：近 OOD 或邊界 → 「需人工確認」，絕不自動「結果」**（L720）。**未來**：kNN 庫更密；收縮 Mahalanobis 與 ViM 可估；OE／守門可行；Roy 顯示專門訓練約 +3–7 AUROC，但需標記離群類別（L722）。

#### A12 學習式影像品質評估與重拍引導（第 12 章，L762–826）
- **結論**：通用 NR-IQA（BRISQUE、NIQE、MUSIQ、CLIP-IQA）**未找到可靠證據**能預測臨床皮膚照片可用性，唯一醫學比較顯示 BRISQUE／NIQE 與專家分數不相關或方向相反；任務專用監督式模型（TrueImage、ImageQX）表現中等且品質標籤雜訊大（模糊一致性高，構圖與解析度低）。**現在**：固定公式維持 warn-only、改在 YOLO 框裁切上計算、開始人工品質標註並量 κ、使用固定具體重拍模板；學習式品質模型與「拒收」模式是未來項目；重拍提示少而具體（模糊優先），只在明顯不可用時觸發（L766）。

#### A15 推論部署效能與佇列（第 15 章，L978–1055）
- **結論**：官方數據 YOLO11n/s 與 YOLO26n/s 在 T4 TensorRT10 單張約 1.5–2.5 ms、CPU ONNX 約 39–90 ms；EfficientNet-B0（0.39 GFLOPS）與 DINOv2-small（21M）也很小；本報告推論：**GPU 運算都不太可能是瓶頸，LINE 下載／回覆網路與排隊才是**，先量測不急著量化。INT8 PTQ 官方建議至少 500 張校正影像，本專案只有約 120 張，醫學影像研究顯示 INT8 PTQ 可能鑑別力下降與校準偏移——現在不建議；FP16 接近 FP32 但必須重新驗證信心門檻。現有佇列（驗簽 → SQLite jobs → 有界 asyncio.Queue → 單一 GPU worker → 45 秒內 reply、否則 push）已合適，不建議 Celery／Redis；主要待改是**影子模型在主 worker 內、回覆後同步執行，會擋住下一張照片**（L982）。

def handle_photo(evt, policy):
    gate = C1_intake(evt, policy)                       # 簽章、去重、時效、同意、配額
    if gate != "accept": return reply_template(gate)
    img = C2_decode_and_privacy(download(evt), policy)  # 格式、像素、臉部
    if img.status != "ok": return log_and_reply(img.status)
    q = C3_quality(img.rgb, box=None, policy=policy)
    if q.decision == "reject": return log_and_reply("retake", reasons=q.reasons)
    z, zc = dinov2(img.rgb), clip(img.rgb)
    o = C4_ood(z, zc, img, policy)                      # kNN 相似度＋CLIP 邊際＋啟發式
    if o.route != "continue": return log_and_reply(o.route)
    det = C5_detect(img.rgb, policy.c_det)
    if det.no_site: return log_and_reply("retake", reasons=["site_not_visible"])
    q2 = C3_quality(img.rgb, box=det.best, policy=policy)   # 在 IV 部位裁切上再算
    pr = C6_classify(img.rgb, det.best)                 # 各折機率、spread
    if pr.disagree: return log_and_reply("needs_review")
    p = C7_calibrate(pr.logits_mean, policy.T)
    S = C8_conformal_set(p, policy.qhat, ordinal=True)
    route = C9_map(S, q2.warn, policy)                  # 見 (a) 對映
    if route == "result_candidate":
        enqueue_human_review(evt, p, S)                 # 現在：結果須人工確認
        route = "needs_review"
    C10_log(evt, q, o, det, pr, p, S, route, policy.version)
    return reply_template(route)
