# 05_匯入區

新進的照片與模型都先放在這裡。**放進來不會自動處理**：一定要到工作台網頁預覽、確認後才會匯入；匯入後原檔仍保留在這裡，不會被搬走或刪除。

| 資料夾 | 放什麼 | 匯入方式 |
|---|---|---|
| `岡山高醫/` | 岡山高醫的照片（檔名 `日期_病歷號_部位_分期_序號.jpg`） | 資料審查 →「外部來源比對與補入」→ 掃描並比對 → 輸入「確認匯入」 |
| `photos/<批次名稱>/` | 其他來源的照片（JPEG、PNG、WEBP） | 資料審查 →「匯入照片」→ 選批次 → 掃描並預覽 → 確認 |
| `models/<模型包名稱>/` | 模型包（一定要附 `package.json`） | 模型與實驗 →「匯入模型」→ 選模型包 → 掃描並預覽 → 確認 |
| `範本/` | `package.json` 範本 | 複製到模型包資料夾後修改 |

## 岡山高醫照片（最常用）

1. 在 `岡山高醫/` 裡新建一個子資料夾（例如 `17\`），把新照片放進去。檔名維持 `日期_病歷號_部位_分期_序號.jpg`：部位 LH／RH／LL／RL，分期 0＝正常、1＝第一期、2＝第二期。
2. 工作台 → 資料審查 →「外部來源比對與補入」→「掃描並比對」。
3. 確認清單後輸入「確認匯入」送出。

- 已匯入過的照片以內容雜湊（SHA-256）判斷，不會重複匯入。
- 新照片依檔名自動完成分類。
- 工作台頁首會提示「岡山高醫新照片」的張數；匯入新照片後也會提醒你做一次完整備份（見 `04_備份/README.md`）。
- 這個資料夾的位置寫在 `02_主程式碼/configs/import_sources.json`（相對於工作區根目錄），整個工作區複製到別台電腦後不用改。

## 其他來源的照片

放在 `photos/<批次名稱>/`。不套用岡山高醫檔名規則，匯入後一律進「待人工審查」，要人工逐張確認。一個批次最多 1000 個檔案。
