# 靜脈炎影像研究工作台（Phlebitis）

在本機電腦上整理靜脈炎照片、人工審查與標註、訓練與評估影像模型，並模擬 LINE 回覆的**研究原型**。模型結果不代表疾病診斷，也不提供嚴重度分級。

## 第一次接手：先做這三件事

1. 讀 [交接說明 HANDOVER](01_文件與紀錄/操作與交付說明/HANDOVER.md)（約 20 分鐘）。
2. 雙擊 `start.bat`，瀏覽器會開啟 http://127.0.0.1:8765 。到「設定與維護 → 環境檢查 → 工作區」，確認每一項都是「正常」。
3. 接上外接硬碟，在「設定與維護 → 完整備份」做一次完整備份（照片與模型目前只有這一份）。

## 日常操作

| 我要… | 做法 |
|---|---|
| 啟動／停止工作台 | 雙擊 `start.bat`／`stop.bat` |
| 用選定模型分析一張照片 | 雙擊 `predict.bat` |
| 換電腦或修復環境 | 雙擊 `setup.bat`（只安裝套件與建置網頁，不動資料） |
| 補入岡山高醫的新照片 | 放進 `05_匯入區/岡山高醫/<新子資料夾>/`，再到「資料審查 → 外部來源比對與補入」 |
| 匯入其他照片或外部訓練的模型 | 見 [05_匯入區/README.md](05_匯入區/README.md) |
| 備份與還原 | 見 [04_備份/README.md](04_備份/README.md) |
| 查文件 | [01_文件與紀錄/INDEX.md](01_文件與紀錄/INDEX.md) |

## 資料夾

| 資料夾 | 放什麼 | 版本控制（git） |
|---|---|---|
| `01_文件與紀錄/` | 交接與操作說明、驗證報告、研究報告、歷史紀錄、LINE 選單素材 | 有（成果報告 .docx 除外） |
| `02_主程式碼/` | 後端 `src`、網頁 `web`、測試 `tests`、腳本 `scripts`、設定 `configs`、Python 環境 `.venv` | 有（`.venv`、`node_modules`、`web/dist` 除外） |
| `03_模型與影像資料/` | 已進系統的照片與標註（data）、模型（models）、訓練評估輸出（runs）、資料庫與暫存（runtime）、原始封存（archive） | 只有 README |
| `04_備份/` | 每日自動備份與修改前副本（完整備份在外接硬碟） | 只有 README |
| `05_匯入區/` | 等待匯入的照片（含岡山高醫原始照片）與模型包 | 只有 README 與範本 |

- 各區的位置寫在 `workspace-layout.json`，程式依此尋找資料；整個 `Phlebitis` 資料夾可以整份複製到別台電腦。
- LINE 金鑰放在根目錄 `.env`（範本：`.env.example`），不要放進程式或 git。
- 命令列操作請在 `02_主程式碼` 內執行，例如 `.\.venv\Scripts\python.exe -m src doctor`；開發說明見 [02_主程式碼/README.md](02_主程式碼/README.md)。

## 重要限制

- **目前模型辨識效果尚未達實用要求**；程式功能完成不等於模型效能達標。
- 正常照片只來自 3 位病人，二分類成績只能當流程驗證。
- 真實 LINE 帳號、HTTPS 與手機收圖尚未驗收；工作台內的「LINE 模擬」不會傳送真實訊息。
- 這裡有病人影像：不要上傳到公開網站或雲端，git 也不要推到公開的遠端。
