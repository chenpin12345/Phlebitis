# Phlebitis 靜脈炎影像研究工作台

日常雙擊本目錄的 `start.bat` 啟動，瀏覽器開啟 http://127.0.0.1:8765；用 `stop.bat` 停止。

| 我要找什麼 | 到哪裡找 |
|---|---|
| 啟動／停止 | 根目錄 `start.bat`／`stop.bat` |
| 安裝或修復環境（換電腦時） | `setup.bat`（只安裝套件與建置網頁，不動資料） |
| 操作手冊、資料與訓練說明 | `01_文件與紀錄/INDEX.md` |
| 驗證報告、測試證據、截圖 | `01_文件與紀錄/驗證報告/` |
| 研究報告（含成果報告、UI 研究） | `01_文件與紀錄/研究報告/` |
| 後端、前端、測試與腳本 | `02_主程式碼/`（說明見其 README） |
| 設定檔（外部來源、服務、研究同意） | `02_主程式碼/configs/` |
| 照片、標註、資料快照 | `03_模型與影像資料/data/` |
| 模型權重與版本 | `03_模型與影像資料/models/` |
| 訓練／評估輸出 | `03_模型與影像資料/runs/` |
| 資料庫、暫存與程式鎖 | `03_模型與影像資料/runtime/` |
| 待匯入的照片與模型包 | `03_模型與影像資料/inbox/`（放入後由網頁預覽確認，不會自動處理） |
| 原始資料與舊版程式封存 | `03_模型與影像資料/archive/` |

各區位置由 `workspace-layout.json` 決定，程式依此尋找資料，不依賴啟動時的工作目錄。LINE 金鑰放在根目錄 `.env`（範本：`.env.example`）。

命令列操作請在 `02_主程式碼` 內執行，例如：

    .\.venv\Scripts\python.exe -m src audit

指令中的 `data/...`、`runs/...` 等相對路徑以 `03_模型與影像資料` 為準。

桌面的「合作醫院」資料夾是唯讀的外部來源，不會被移動或修改。本系統是研究原型，模型結果不代表疾病診斷。

## 版本歷程

每個版本是一個 commit，並有對應的 tag，可在 GitHub 的 Tags 頁面瀏覽或下載。

| Tag | 內容 |
|---|---|
| `v0-original` | 最初的 YOLO 訓練與推論腳本 |
| `v1` | 研究工作台第一版（FastAPI 後端 + React 前端、LINE Bot） |
| `v2` | 工作台擴充：資料審查、模型比較、監控、維護與垃圾桶 |
| `v3` | 前後端依功能分區重構、照片／模型匯入、效能量測 |
| `v4` | 目前版本：01／02／03 資料夾分區 |

## 隱私

本倉庫只包含程式碼與文字文件，以下內容沒有上傳：

- 病患照片、標註、資料快照（`03_模型與影像資料/`）
- 模型權重、訓練輸出、資料庫
- 含照片的截圖、成果報告（.docx）
- 金鑰（`.env`）

文件與測試中的影像檔名已去識別化：拍攝日期改為 `202601xx`，床號改為 `BEDxx`，合作醫院名稱與本機路徑已移除。
