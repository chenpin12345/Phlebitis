# 04_備份

這裡放「工作台自動產生的備份」。照片與模型的**完整備份**不在這裡，而是在你於設定頁指定的外接硬碟（見下方第 3 節）。

| 資料夾 | 內容 | 由誰產生 | 保留多久 |
|---|---|---|---|
| `工作台紀錄/` | 每日自動、手動、還原前、匯入前的 zip | 工作台（設定 → 每日自動備份） | 每種保留 14 份（可在設定頁調整） |
| `修改前副本/manifest/` | 修改照片清單（manifest）之前的 CSV 副本 | 資料搬移與檔名規則程式 | 永久保留 |
| `修改前副本/資料庫/` | 資料庫升級前的 sqlite 副本 | 資料庫升級程式 | 永久保留 |

位置由根目錄 `workspace-layout.json` 的 `"backups"` 決定；程式不依賴啟動時的工作目錄。

## 1. 每日自動備份（工作台紀錄）

- 工作台開著時每天自動做一份，約 9 MB。
- **包含**：照片清單、標註、審查紀錄、標籤證據、來源名稱、資料庫、設定與模型引用。
- **不包含**：照片本身、模型權重、訓練輸出。這些請用第 3 節的完整備份。
- 還原：工作台 → 設定與維護 → 每日自動備份 → 選一份按「還原…」。還原前系統會先把目前狀態另存成一份「還原前」備份，所以還原後仍可再還原回來。
- 模型引用（本地模擬、LINE 使用中的模型）與設定檔永遠不會被自動還原。

## 2. 修改前副本

程式在大量修改資料前會先留一份副本，萬一結果不對可以人工比對或換回：

- `manifest/manifest-before-<動作>-<時間>.csv`：當時的 `data/manifest.csv`。對應的修改紀錄在 `03_模型與影像資料/data/migrations/`。
- `資料庫/before-<版本>.sqlite3`：資料庫升級前的完整資料庫。`-wal`、`-shm` 是同一份資料庫的附屬檔，要一起保留。

2026-10-17 以前這些副本放在 `03_模型與影像資料/runtime/backups/` 與 `runtime/workbench/backups/`；當時寫下的修改紀錄仍是舊路徑，實際檔案已搬到這裡（搬移紀錄：`01_文件與紀錄/驗證報告/verification/2026-10-17_交接整理/data-moves.json`）。

## 3. 完整備份（外接硬碟）

設定頁 → 完整備份。第一次使用時：

1. 接上外接硬碟（建議開啟 BitLocker 加密；這是病人影像）。
2. 在「完整備份設定」填入硬碟上的資料夾，例如 `E:\靜脈炎完整備份`，按「儲存位置」。
3. 按「立即完整備份」。第一次約 2 GB，之後每次只複製新增或變更的檔案。

**備份範圍**：照片與標註（data）、模型（models）、原始資料封存（archive）、05_匯入區（含岡山高醫原始照片）、資料庫、設定（configs）、這個資料夾的每日備份、匯入收據。訓練輸出（runs）可在設定中勾選。

**外接硬碟裡的結構**：

```
靜脈炎完整備份\
├─ 目前檔案\          最新的完整內容，可以直接用檔案總管打開
├─ 舊版本\<時間>\      那次備份時被修改或被刪除的檔案的舊版
├─ 清單\<時間>.json    那次備份每個檔案的大小與 SHA-256
└─ 清理紀錄.json       自動清理刪除了哪些舊版本
```

**舊版本自動清理（預設 30 天）**：

- 只在「完整備份成功之後」才清理；備份失敗或很久沒備份時，什麼都不刪。
- 依清單記錄的備份完成時間判斷，刪除超過 30 天的 `舊版本\<時間>\` 與清單；最新一份清單永遠保留。
- 結果：最近 30 天內的每一次備份都能完整還原，更早的還原點不再提供。
- 名稱不是系統格式、沒有清單、含捷徑或 junction、時間在未來的資料夾一律跳過。`目前檔案\` 永遠不會被清理。

**提醒**：超過 7 天沒做完整備份、或匯入新照片後尚未完整備份，工作台頁首的「通知」會提醒。只認工作台做的完整備份；自己用檔案總管複製的不算。

**核對**：按「核對備份」會逐檔比對 SHA-256，回報缺少或內容不符的檔案。

### 從完整備份還原

系統不會直接覆蓋正式資料。步驟：

1. 設定頁 → 完整備份 → 在要退回的那一次按「還原…」，填一個**空資料夾**（例如 `E:\還原_20261017`），等通知顯示完成。
2. 執行根目錄 `stop.bat` 關閉工作台。
3. 把要被替換的資料夾**先改名保留**（例如 `data` → `data_替換前_20261017`），不要直接刪除。
4. 依下表把還原資料夾的內容複製回原位：

| 還原資料夾內 | 放回 |
|---|---|
| `data\` | `03_模型與影像資料\data\` |
| `models\` | `03_模型與影像資料\models\` |
| `archive\` | `03_模型與影像資料\archive\` |
| `runtime\imports\` | `03_模型與影像資料\runtime\imports\` |
| `database\workbench.sqlite3` | `03_模型與影像資料\runtime\workbench\workbench.sqlite3`（舊的 `workbench.sqlite3`、`-wal`、`-shm` 先改名保留） |
| `configs\` | `02_主程式碼\configs\` |
| `匯入區\` | `05_匯入區\` |
| `工作台紀錄\` | `04_備份\工作台紀錄\` |
| `runs\`（有勾選時） | `03_模型與影像資料\runs\` |

5. 執行 `start.bat`，到「設定與維護 → 環境檢查」與「資料審查」確認照片數量正確，再刪除改名保留的舊資料夾。
